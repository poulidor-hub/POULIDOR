La commande à ne jamais lancer

⚠ Règle d'or Ne faites JAMAIS docker compose down -v. Le drapeau -v supprime les volumesLe stockage persistant des bases de données. Le supprimer efface toutes les données. : toutes les données de l'app sont détruites.

Objectif de cette page

Comprendre pourquoi cette commande est dangereuse et quoi faire à la place.

Quand vous risquez de la croiser

Dans des tutoriels Docker génériques, ou par copier-coller. Sur POULIDOR, arrêtez toujours une app par make down (sans -v) ou via hubctl.

À faire à la place

make down     # arrête les services, GARDE les données
./hubctl      # menu → Hub → Start/Stop
En coulisse (technique)

down arrête et supprime les conteneurs et le réseau, mais conserve les volumes nommés. -v ajoute la suppression de ces volumes — irréversible.

En cas de problème

Si les volumes ont été supprimés, seule une sauvegarde (coffre, backup d'app, ou park-export) permet de restaurer. Voir park-export / restore.
