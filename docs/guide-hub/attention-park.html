park-export / park-restore

Objectif

Exporter tout le parc (ou une app) dans une archive tar.gz, et la restaurer sur un autre Hub.

Quand l'utiliser

Migration vers un nouveau serveur, sauvegarde hors-ligne complète.

Commandes

./hubctl park-export                      # tout le parc → tar.gz
./hubctl park-export --app exemple-apps  # une seule app
./hubctl park-restore park.tar.gz         # restauration
⚠ Restauration sur Hub VIERGE uniquement park-restore ne fonctionne que sur un Hub neuf, sans données. Il n'y a pas de --force : impossible d'écraser un parc existant.
En coulisse (technique)

L'export empaquette le code, les .env et les données des volumes. La restauration refuse de s'exécuter si le Hub contient déjà des données, pour éviter tout écrasement accidentel.

En cas de problème

Si park-restore refuse de s'exécuter, c'est que le Hub cible n'est pas vierge. Repartez d'une installation neuve du Hub.
