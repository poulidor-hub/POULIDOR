Commandes make par application

Chaque app dans APPS/ et APP_Workshop/ possède un Makefile standard. Ces commandes se lancent depuis le dossier de l'app.

Cycle de vie

CommandeRôle
make sync-envAlloue les ports via le Hub et synchronise le .env (après toute modif de .env ou VERSION).
make devMode développement : reconstruit et affiche les logs en direct.
make upDémarre en arrière-plan (sans reconstruire).
make downArrête tous les services.
make restart-apiRedémarre uniquement l'API.
make restart-frontendRedémarre uniquement le frontend.

Tests et santé

CommandeRôle
make testTests sur l'hôte (SQLite, rapide).
make test-dockerTests dans le conteneur (miroir de la production).
make test-covTests avec couverture.
make healthGET /api/health.
make health-detailedGET /api/health/detailed.

Versions

make bump-patch    # x.y.Z  (correctif)
make bump-minor    # x.Y.0  (nouvelle fonctionnalité)
make bump-major    # X.0.0  (changement majeur)

Nettoyage

Attention aux commandes de nettoyage
  • make clean supprime les conteneurs, les volumes et les caches : les données de l'app sont perdues.
  • make clean-all supprime en plus les images Docker.
Ne les utilisez que si vous avez une sauvegarde ou si l'app n'a pas de données importantes.
En coulisse (technique)

Ces cibles enveloppent docker compose. make dev équivaut à un rebuild suivi d'un up en avant-plan. make sync-env interroge le Hub pour réserver des ports uniques avant de réécrire le .env.
