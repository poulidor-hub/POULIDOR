Coffre : les secrets chiffrés

Objectif

Sauvegarder et restaurer de façon chiffrée tous les secrets du parc (fichiers .env, secrets du Hub) sous une seule passphrase maître.

Quand l'utiliser

Après toute modification de secrets, avant une suppression d'app, ou pour récupérer un .env perdu.

Étapes dans hubctl

  1. Configuration (3) → Coffre (5).
  2. Saisir la passphrase pour déverrouiller.
  3. Choisir : 💾 Sauvegarder, ⬇ Récupérer (export), ou 🔑 Changer la passphrase.

Une entrée marquée [MODIFIÉ] signale un .env qui diverge de la version sauvegardée.

En coulisse (technique)

Les secrets sont chiffrés (FernetChiffrement symétrique authentifié.) dans hubctl_cli/vault/parc.vault.enc. La passphrase n'est jamais stockée. Sources lues : HUB_base/.env, APPS/*/.env, HUB_base/secrets/. Une sauvegarde automatique est faite avant toute suppression d'app.

⚠ Passphrase IRRÉCUPÉRABLE Si vous perdez la passphrase maître, les secrets sont définitivement inaccessibles. Notez-la dans un gestionnaire de mots de passe sûr.
En cas de problème

Passphrase refusée : vérifiez la casse et la disposition du clavier. En cas de divergence [MODIFIÉ], choisissez si vous sauvegardez la version locale ou récupérez la version du coffre.
