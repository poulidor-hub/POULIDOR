Ajouter une application

Objectif

Installer une nouvelle application dans le parc, soit en clonant un dépôt git, soit en rattachant une app déjà présente.

Quand l'utiliser

À la mise en service d'une nouvelle application.

Étapes dans hubctl

  1. Apps (1) → Ajouter une app (2).
  2. Choisir Cloner depuis une URL git ou Rattacher une app existante.
  3. Pour un clone : saisir l'URL (ex. git@github.com:Poutchouli/exemple-app-2.git).
  4. Accepter de lancer INITIALISE.py quand proposé.
Contenu de démo Par défaut, INITIALISE.py nettoie le contenu de démonstration. Lancez-le avec --demo pour le conserver et explorer l'app.
En coulisse (technique)

Le clone hérite des droits SSH du serveur et atterrit dans APPS/<nom-du-dépôt>. INITIALISE.py exécute 14 étapes (.env, docker-compose, config, frontend, tests, VERSION, CHANGELOG). Une garde disque s'applique.

⚠ Points d'attention
  • Vérifiez l'espace disque avant un gros clone (refus sous 5 % libre).
  • Le nom du dossier vient du nom du dépôt : choisissez un dépôt bien nommé.
En cas de problème

Échec du clone : vérifiez l'URL et les droits SSH du serveur. Échec de INITIALISE.py : relancez-le manuellement depuis le dossier de l'app.
