Supprimer une application

Objectif

Retirer une application du parc, avec filet de sécurité (coffre + sauvegarde + corbeille).

Quand l'utiliser

Quand une app n'est plus utilisée, ou pour la réinstaller proprement.

Comment faire

La suppression passe par hubctl app remove : sauvegarde automatique, arrêt avec volumes, puis retrait du dossier de l'app — après confirmation.

./hubctl app remove <slug>             # supprime l'app (confirmation interactive)
./hubctl app remove <slug> --dry-run   # voir d'abord ce qui serait supprimé

Le déroulé : backup tar.gz de l'app, puis compose down -v (conteneurs et volumes, base incluse), puis retrait du dossier APPS/<slug>. Répondre O pour confirmer ; --yes passe la confirmation (scripts, CI).

En coulisse (technique)

Avant suppression, hubctl synchronise le coffre et crée une archive tar.gz dans hubctl_src/hubctl_cli/backups/, puis arrête le projet compose avec ses volumes (down -v) et supprime APPS/<slug> (hubctl 0.24.0).

⚠ Points d'attention
  • down -v détruit les volumes Docker : les données de la base ne sont conservées que dans le backup tar.gz — vérifiez-le avant de confirmer.
  • Les archives s'accumulent dans hubctl_src/hubctl_cli/backups/ : pensez à l'espace disque.
  • La commande agit sur une seule app : relisez le slug demandé avant de confirmer.
En cas de problème

Pour remonter une app supprimée par erreur : réinstallez-la depuis son dépôt git (./hubctl app install <url-git>), puis restaurez ses données depuis l'archive tar.gz de hubctl_src/hubctl_cli/backups/.
