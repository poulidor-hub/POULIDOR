# APPS/

Ce dossier contient les applications en **production** du parc POULIDOR.
Chaque sous-dossier est une app autonome avec son propre dépôt git.

Ce dossier est ignoré par git (`APPS/*` dans `.gitignore`), seul ce fichier est suivi.
Les applications sont clonées individuellement via `manifest.json` ou `hubctl`.
