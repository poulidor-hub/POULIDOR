# APP_Workshop/

Ce dossier contient les applications en **cours de développement** (mode atelier).
Les apps déplacées ici depuis `APPS/` reçoivent le suffixe `-ws` et tournent en mode dev.

Ce dossier est ignoré par git (`APP_Workshop/*` dans `.gitignore`), seul ce fichier est suivi.
Utiliser `app-workshop-mover` pour déplacer une app entre APPS/ et APP_Workshop/.
